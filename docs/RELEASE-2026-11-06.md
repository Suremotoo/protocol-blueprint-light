# Marketplace update · 2026-11-06

Verified on the signed-in marketplace dashboards before building:

- JetBrains approved version 1.1.0 → update 1.1.1.
- VS Code public version 1.1.1 → update 1.1.2.

Local experiment versions 1.2.0–1.2.3 were not published and are not used as marketplace versions.

The accepted local 1.2.3 color resources and Java annotator are retained. Java PSI/AnnotationBuilder tests, eight modifier-chain cases, cached-scheme fallbacks and native VS Code TextMate per-character regression comparisons passed during local testing.

VS Code's old packaged README rewrote images to `/raw/HEAD/images/`, omitting the monorepo `vscode/` directory. This update uses a complete HTTPS PNG URL pinned to tag `release-idea-1.1.1-vscode-1.1.2`; build defaults also specify the correct image/content base. The old images are replaced with one promotional illustration, clearly labeled as an illustration.

Full GUI/daemon regression has not been completed. Marketplace status is reported separately from upload acceptance.

The release source and fixed-image tag have been pushed. The pinned PNG returned HTTP 200 with image/png and 190417 bytes; GitHub README rendered it at 1500 × 990. Both marketplace uploads were accepted; JetBrains reported additional moderation, and VS Code showed Verifying for 1.1.2.

Users running a local 1.2.x experiment have a numerically higher version than these official releases; automatic updates will not downgrade it. To switch to the store build, manually install the official package (or remove the local experiment first).
